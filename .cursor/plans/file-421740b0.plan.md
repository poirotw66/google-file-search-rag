# Google File Search RAG 應用

```
google-file-search-rag/
├── backend/
│   ├── main.py          # FastAPI 應用入口

│   │   ├── upload.py    # 檔案上傳 API
│   │   └── chat.py      # 對話 API
│   ├── services/
│   │   └── gemini.py    # Google Gemini File Search 封裝
│   └── requirements.txt

│   ├── src/
```

## Backend 實作

### 1. Session 管理

- 建立 session 時自動建立對應的 File Search Store
- 儲存 session_id 與 file_search_store_name 的對應關係（記憶體中）
- Session 結束時清理 Store

### 2. 檔案上傳 API

- 接收 multipart/form-data
- 呼叫 `upload_to_file_search_store` 將檔案匯入
- 等待 operation 完成後回傳成功

### 3. 對話 API  

- 接收使用者訊息與 session_id
- 使用該 session 的 File Search Store 進行 RAG 查詢
- 回傳 AI 回應與引用資訊

## Frontend 實作

### 1. 主介面

- 左側：已上傳檔案列表
- 右側：對話視窗

### 2. 檔案上傳

- 拖放或點擊上傳
- 顯示上傳進度與狀態
- 支援 PDF、Word、圖片等格式

### 3. 對話介面

- 訊息氣泡顯示
- 顯示 AI 回應的引用來源
- 輸入框與送出按鈕

## 技術細節

- Backend: FastAPI + google-genai SDK
- Frontend: React + TypeScript + Vite
- 樣式: Tailwind CSS
- 狀態管理: React hooks (useState, useEffect)
